# Automations

This workspace keeps each automation in its own project folder.

- `racquetball-reservation/` — Chandler racquetball reservation automation
- `commute-trip-recording/` — monthly Commute with Enterprise trip recording automation

The racquetball automation's currently open Edge profile remains at
`../Automations/.hybrid-edge-profile/` and is linked into its project folder so
the active signed-in browser session is not disrupted.
